## 贝塞尔曲线（Bézier Curve）简介
贝塞尔曲线用几个控制点定义一条平滑曲线，在机械臂轨迹规划、动画、CAD、字体设计中都很常见。

### 1. 最简单的二次贝塞尔曲线
给定三个点：
$P_0,\quad P_1,\quad P_2$  
其中：  
* **$P_0$**：起点
* **$P_2$**：终点
* **$P_1$**：控制点
**曲线公式：**
$$B(t)=(1-t)^2P_0+2(1-t)tP_1+t^2P_2, \quad t\in[0,1]$$
**示意图：**
```text
          P1 ●
            / \
           /   \
P0 ●~~~~~~      ● P2

```
* 当 $t=0$ 时：$B(0)=P_0$
* 当 $t=1$ 时：$B(1)=P_2$
因此曲线一定从 $P_0$ 出发，最终到达 $P_2$。

### 2. 最常用的三次贝塞尔曲线
机械臂和图形中更常见的是三次贝塞尔曲线，由四个控制点定义：
$P_0,P_1,P_2,P_3$
**曲线公式：**
$$B(t) = (1-t)^3P_0 + 3(1-t)^2tP_1 + 3(1-t)t^2P_2 + t^3P_3, \quad t\in[0,1]$$
**结构示意：**
```text
P0 ●---------------------● P3
    \                   /
     ● P1           P2 ●

```

* **$P_0$**：起点
* **$P_3$**：终点
* **$P_1, P_2$**：控制曲线形状


### 3. 它和机械臂轨迹有什么关系？
假设机械臂起点和终点分别是 $q_0$ 和 $q_f$，可以使用三次贝塞尔曲线定义轨迹：
$$q(t) = (1-t)^3P_0 + 3(1-t)^2tP_1 + 3(1-t)t^2P_2 + t^3P_3$$
其中： 
* **$P_0$** $\to$ 起始关节位置  
* **$P_3$** $\to$ 目标关节位置  
* **$P_1$** $\to$ 起始运动趋势  
* **$P_2$** $\to$ 结束运动趋势  
例如对于 14 自由度机械臂：  
$$P_0,P_1,P_2,P_3\in\mathbb{R}^{14}$$  
也就是说，每个控制点都是一个向量：  
$$P_0 = [q_1, q_2, q_3, \dots, q_{14}]$$  
因此贝塞尔曲线可以直接用于**关节空间轨迹平滑插补**。 

### 4. 一个最简单的 C++ 例子
**三次贝塞尔函数定义：**
```cpp
Eigen::VectorXd bezier(
    double t,
    const Eigen::VectorXd& P0,
    const Eigen::VectorXd& P1,
    const Eigen::VectorXd& P2,
    const Eigen::VectorXd& P3)
{
    return
        std::pow(1.0 - t, 3) * P0 +
        3.0 * std::pow(1.0 - t, 2) * t * P1 +
        3.0 * (1.0 - t) * t * t * P2 +
        t * t * t * P3;
}

```

### 5. 和 B 样条简单区别

| 特性 | 贝塞尔曲线 (Bézier) | B 样条 (B-Spline) |
| --- | --- | --- |
| **控制点数量** | 通常 3～4 个 | 可以很多 |
| **是否经过中间控制点** | 通常不经过 | 通常也不经过 |
| **起点终点** | 一定经过 $P_0, P_n$ | 取决于节点矢量（Knot Vector） |
| **局部修改** | 修改一个控制点影响整条曲线 | 修改控制点主要影响局部 |
| **适用场景** | 简单平滑曲线 | 多 Waypoint 轨迹 |

## 总结
对于机械臂轨迹规划问题，可以按如下逻辑选择：  
* **两个点之间平滑运动** $\to$ **贝塞尔曲线**  
* **很多路径点整体平滑** $\to$ **B 样条 / CubicSpline**  
* **已经有路径，只需要确定速度和时间限制** $\to$ **TOPPRA**  
> **Bezier、B 样条**主要解决“**路径形状**”问题；而 **TOPPRA** 主要解决“**沿着路径怎么满足速度、加速度限制地运动**”问题。
