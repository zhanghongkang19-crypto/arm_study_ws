## B样条曲线定义：
B 样条曲线是一种由以下要素共同决定的参数曲线：  
* **控制点（Control Points）**  
* **节点向量（Knot Vector）**  
* **B 样条基函数（Basis Functions）**  
* **曲线次数（Degree）**  

### 数学定义
$$C(u)=\sum_{i=0}^{n} P_i N_{i,p}(u)$$  

| 符号 | 含义 |
| --- | --- |
| $C(u)$ | B 样条曲线上的点 |
| $u$ | 曲线参数 |
| $P_i$ | 第 $i$ 个控制点 |
| $N_{i,p}(u)$ | 第 $i$ 个 $p$ 次 B 样条基函数 |
| $p$ | 曲线次数 |
| $n$ | 控制点数量 $- 1$ |

### 控制点
控制点序列 $P_0, P_1, \dots, P_n$ 决定了曲线的整体形状。
```text
控制点分布:
P0          P3
    P1  P2

生成的 B 样条曲线:
    ______
  /
 /
```
> **注意**：B 样条曲线通常不直接经过控制点，控制点主要起到对曲线的“吸引/拉拽”作用。  

###  节点向量（Knot Vector）
节点向量是参数轴上的一组单调递增的值：
$$U = [u_0, u_1, \dots, u_m]$$
**三次 B 样条示例**：
$$U = [0, 0, 0, 0, 1, 2, 3, 4, 4, 4, 4]$$ 
其中 $0, 1, 2, 3, 4$ 为参数位置。节点向量决定了：  
* 哪些控制点参与曲线生成  
* 每个控制点的局部影响范围  
* 曲线在拐点处的连续性  

###  次数 $p$
曲线次数 $p$ 决定了每个基函数的阶数：  
| $p$ 值 | 名称 | 形状特征 |
| --- | --- | --- |
| **0** | 0 次 | 矩形 / 阶梯状 |
| **1** | 1 次 | 三角形 / 折线 |
| **2** | 2 次 | 二次抛物线 |
| **3** | 3 次 | 三次多项式曲线 |
> 在机器人轨迹规划中，通常取 **$p = 3$**。

###  B样条基函数定义
基函数 $N_{i,p}(u)$ 表示：**第 $i$ 个控制点在参数 $u$ 处的权重**。
$$C(u) = P_0 N_{0,p}(u) + P_1 N_{1,p}(u) + \dots + P_n N_{n,p}(u)$$
$$\text{曲线点} = \sum (\text{控制点} \times \text{对应权重})$$

### 0次 B 样条基函数
作为递推的基础，0 次基函数定义为开关函数：
$$N_{i,0}(u) = \begin{cases} 1, & u_i \le u < u_{i+1} \\ 0, & \text{其他} \end{cases}$$
即当参数 $u$ 落在区间 $[u_i, u_{i+1})$ 内时，第 $i$ 个基函数权重为 $1$，否则为 $0$。
```text
N_{i,0}(u) 示意图:

  _____  (值为 1)
 |     |
 |     |______ (值为 0)
u_i   u_{i+1}

```
###  Cox-de Boor 递推公式
高阶 B 样条基函数由低阶基函数递推合成：
$$N_{i,p}(u) = \frac{u - u_i}{u_{i+p} - u_i} N_{i,p-1}(u) + \frac{u_{i+p+1} - u}{u_{i+p+1} - u_{i+1}} N_{i+1,p-1}(u)$$
$$\text{高阶基函数} = \text{左边低阶项加权} + \text{右边低阶项加权}$$
* **一次基函数 $N_{i,1}$**：由 $N_{i,0}$ 与 $N_{i+1,0}$ 组合而成  
* **二次基函数 $N_{i,2}$**：由 $N_{i,1}$ 与 $N_{i+1,1}$ 组合而成  

###  节点数量关系
已知控制点数量为 $n + 1$，曲线次数为 $p$，则节点总数量为：
$$m + 1 = n + p + 2 \quad \implies \quad m = n + p + 1$$

###  推导说明
每个 $p$ 次基函数 $N_{i,p}$ 需要 $p + 2$ 个节点作为支撑范围。对于 $n + 1$ 个基函数，组合后的节点向量末尾索引满足 $m = n + p + 1$。

###  局部支撑性质
一个 $p$ 次 B 样条基函数 $N_{i,p}(u)$ 仅在以下区间内非零：
$$u \in [u_i, u_{i+p+1})$$
对于三次 B 样条（$p = 3$），基函数影响范围为 $[u_i, u_{i+4})$。因此，**曲线上的任意一个点只受到 $p + 1 = 4$ 个控制点的影响**。

###  连续性
若节点在节点向量中的重复出现次数为 $k$（重复度），则曲线在该节点处的连续性为：
$$C^{p - k}$$
**以三次 B 样条（$p = 3$）为例**：  
* **节点不重复（$k = 1$）**：具备 $C^2$ 连续性（位置、速度、加速度均连续）。  
* **节点重复 2 次（$k = 2$）**：具备 $C^1$ 连续性（位置、速度连续，加速度突变）。  

###  节点向量
节点向量是 B 样条定义中的一个重要组成部分，它对曲线的形状和性质有着重要影响。  
* **节点的取值范围**：节点的值通常在一个特定的区间内，并且按照一定的顺序排列。一般来说，节点向量的首尾节点值会重复一定次数，例如对于一个三次 B 样条曲线，节点向量的首尾通常各重复三次。  
* **节点的分布**：节点的分布方式可以是均匀的（Uniform），即相邻节点之间的间隔相等；也可以是非均匀的（Non-uniform），即相邻节点之间的间隔不相等。不同的节点分布方式会导致曲线具有不同的特性。均匀分布的节点通常会生成较为规的  曲线，而非均匀分布的节点可以更好地适应一些特殊的形状要求或数据分布情况。  

节点向量 $U$ 在 B 样条的定义中起着关键作用。它是一个非递减的实数序列，其元素决定了 B 样条曲线在不同区间上的行为。节点向量可以分为均匀节点向量（Uniform Knot Vector）和非均匀节点向量（Non-Uniform Knot Vector）两种类型：1. 均匀节点向量：在均匀节点向量中，相邻节点之间的间隔是相等的。
例如，一个常见的均匀节点向量形式为：$$U = [0, 1, 2, \dots, m]$$
均匀节点向量使得 B 样条曲线在各段上具有较为规则的形状和性质，常用于一些对曲线形状要求相对简单、规律性强的应用场景。

非均匀节点向量：
非均匀节点向量中相邻节点之间的间隔不相等。通过精心设计非均匀节点向量，可以实现对 B 样条曲线形状的精细控制，例如在曲线的某些部位增加节点密度，以更好地拟合特定的形状或数据点。

####  定义与构成
节点向量是一个非递减的实数序列，记为 $U = [u_0, u_1, \dots, u_m]$，其中 $m = n + p + 1$，这里的 $n + 1$ 是控制点的数量，$p$ 是 B 样条曲线的次数（Degree）。
例如，若有 5 个控制点（$n = 4$），曲线次数为 3（$p = 3$），那么节点向量的长度 $m$ 应为 $4 + 3 + 1 = 8$，可能是形如 $[u_0, u_1, \dots, u_8]$ 的一个实数序列。

####  作用
节点向量主要起到以下几个方面的作用：
1. 界定曲线参数范围：
* B 样条曲线上任意一点 $P(u)$ 的参数 $u$ 的取值范围通常是由节点向量来界定的。一般来说，有效参数区间是从第 $p$ 个节点到倒数第 $p + 1$ 个节点，即 $u \in [u_p, u_{m-p}]$。
* 例如，对于上述提到的节点向量 $[u_0, u_1, \dots, u_8]$，若 $p = 3$，则参数 $u$ 的有效取值范围是 $[u_3, u_{8-3}] = [u_3, u_5]$。
2. 确定曲线段的划分与连接方式：
* 节点向量中的节点将整个 B 样条曲线划分为若干个曲线段。相邻节点之间的区间对应着不同的曲线段，曲线在这些节点处按照一定的连续性条件进行连接。
* 不同的节点分布会导致曲线段的长度、形状以及连接的平滑程度有所不同。比如，节点分布较为密集的的区域，曲线段相对较短，且曲线在该区域的变化可能相对更平缓。

####  影响曲线的形状和对控制点的敏感性：
* 通过精心设计节点向量，可以实现对 B 样条曲线形状的精细控制。例如，在需要曲线在某个局部区域有更复杂的形状变化时，可以在该区域增加节点的密度。
* 同时，节点向量也会影响到改变一个控制点的位置时对曲线形状的影响程度。一般来说，在节点密集区域改变控制点对曲线形状的影响相对较小，而在节点稀疏的区域改变控制点可能会对曲线形状产生更明显的影响。

#### 类型
节点向量可以分为以下两种主要类型：
1. 均匀节点向量（Uniform Knot Vector）：
* **定义**：在均匀节点向量中，相邻节点之间的间隔是相等的。常见的均匀节点向量形式有多种，比如：
* 对于开区间形式的均匀节点向量，若曲线次数为 $p$，控制点数量为 $n + 1$，其形式可能为：
$$U = [0, 1, \dots, p, p + 1, \dots, n + 1, n + 2, \dots, n + p + 1]$$
* 对于闭区间形式的均匀节点向量，例如：
$$U = [0, 0, \dots, 0, 1, 1, \dots, 1] \quad (\text{这里前面有 } p + 1 \text{ 个 } 0 \text{，后面有 } p + 1 \text{ 个 } 1)$$
* **特点及应用**：
* 均匀节点向量使得 B 样条曲线在各段上具有较为规则的形状和性质。因为节点间隔均匀，所以曲线段的长度相对比较一致，曲线在各节点处的连续性表现也较为规律。
* 常用于一些对曲线形状要求相对简单、规律性强的应用场景，比如绘制一些简单的几何图形、生成规则的曲线轮廓等。

2. 非均匀节点向量（Non-Uniform Knot Vector）：
* **定义**：非均匀节点向量中相邻节点之间的间隔不相等。其形式可以根据具体需求进行灵活设计，例如：
$$U = [0, 0, 0, 0.2, 0.5, 0.8, 1, 1, 1]$$
* **特点及应用**：
* 通过精心设计非均匀节点向量，可以实现对 B 样条曲线形状的精细控制。例如，可以在曲线的某些部位增加节点密度，以更好地拟合特定的形状或数据点。
* 在需要精确拟合复杂形状、模拟不规则曲线变化或者根据具体数据点来生成曲线时，非均匀节点向量就显得尤为重要。比如在计算机图形学中，根据用户绘制的不规则曲线路径来生成对应的 B 样条曲线，就可能会使用非均匀节点向量来更好地捕捉曲线的细节特征。

### 性质
B 样条曲线具有以下一些重要性质：
1. 局部控制性：只改变一个控制点的位置，只会影响到与该控制点相关的一小部分曲线段，而不会对整个曲线产生全局性的影响。这使得用户可以方便地通过调整个别控制点来精细地修改曲线的形状。
2. 连续性：根据 B 样条曲线的次数和节点向量的设置，曲线在节点处可以实现不同程度的连续性。例如，对于三次 B 样条曲线（$p = 3$），在一般情况下，曲线在节点处具有二阶连续性（即曲线的一阶导数和二阶导数都是连续的），这使得曲线看起来非常光滑。
3. 插值与逼近：B 样条曲线既可以用于插值，即通过调整控制点使得曲线精确地通过给定的一些数据点；也可以用于逼近，即曲线不一定要精确通过给定的数据点，而是以一种较为平滑的方式靠近它们，这种特性在数据拟合等应用场景中非常有用。
综上所述，B 样条通过控制点、节点向量以及 B 样条基函数等要素来定义一种具有良好性质的分段多项式曲线，在众多领域有着广泛的应用。
